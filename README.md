# Sistema de Gerenciamento de Supermercado

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)

Sistema de gerenciamento de produtos desenvolvido em Python, com operações completas de **CRUD** (Create, Read, Update, Delete) via terminal. Projeto desenvolvido como trabalho acadêmico no curso de Tecnólogo em Ciência de Dados — Unifecaf.

---

## Funcionalidades

- **Adicionar** novos produtos ao sistema
- **Visualizar** todos os produtos cadastrados
- **Atualizar** informações de um produto existente
- **Excluir** produtos do sistema

---

## Tecnologias utilizadas

- **Python 3.13**
- **Pandas 2.3.3**

---

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/MthLeal/sistema_supermercado.git
```

2. Acesse a pasta do projeto:
```bash
cd sistema_supermercado
```

3. Execute o programa:
```bash
python aplicacao/main.py
```
